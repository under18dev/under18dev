# U18 Dev - Design System

## Overview

U18 Dev (Under18 Developers) is a modern technology organization for ambitious young developers.

This is NOT a casual student community website.

The design should feel like:
- a modern startup
- a developer-focused organization
- a future tech company
- minimal, clean, and trustworthy

The site must communicate:
- professionalism
- passion for technology
- long-term vision
- developer culture
- seriousness and credibility

Avoid "student club" aesthetics.

# Typography

## Fonts

Primary Font:
Inter or Geist

Monospace Font:
JetBrains Mono

---

## Typography Style

Large bold headlines.
Strong spacing.
Readable layouts.
Minimal decorative elements.

Headlines should feel confident and modern.

Example:
- large hero titles
- bold section headers
- clean paragraph spacing

---

# Layout

Use a clean grid system.

Spacing is extremely important.

Prefer:
- large whitespace
- centered content
- max-width containers
- subtle borders
- section separation

Avoid:
- crowded layouts
- over-designed components
- excessive animations

---

# Animations

Animations should be subtle.

Allowed:
- fade in
- slight hover effects
- smooth transitions

Avoid:
- heavy parallax
- flashy motion
- spinning elements
- gaming-style effects

---

# Visual Elements

Allowed:
- subtle grid backgrounds
- thin borders
- code snippets
- terminal-inspired UI
- minimal geometric shapes

Avoid:
- anime aesthetics
- gamer RGB aesthetics
- excessive glow effects
- noisy backgrounds

---

# Tone

The site should feel:
- serious
- ambitious
- intelligent
- technical
- future-oriented

NOT:
- childish
- overly playful
- meme-focused

---

# Website Structure

## 1. Hero Section

Large typography-focused hero section.

Include:
- organization name
- short mission statement
- CTA buttons

Example mood:
"Technology has no age limit."

Buttons:
- Join Community
- Activities
- YouTube

---

## 2. About Section

Explain:
- what U18 Dev is
- why it exists
- what it supports

Focus on:
- young developers
- learning
- building
- sharing knowledge

---

## 3. Activities Section

Card-based layout.

Examples:
- Tech Talks
- Community Events
- YouTube Content
- Open Source
- Member Projects

---

## 4. Vision Section

A strong philosophical statement.

Should communicate:
- opportunity
- technology
- growth
- challenging age barriers

---

## 5. Team Section

Minimal team cards.

Include:
- icon/avatar
- name
- role
- links

Simple and clean.

---

## 6. Footer

Minimal footer.

Include:
- GitHub
- X/Twitter
- YouTube
- Contact
